# 布局模板

> 模板决定「什么比例的图占多宽、要不要浮动」。内置的 auto 是一条曲线；自定义模板用区间规则替换它。

![方图|ag:width=60%](assets/photo/06-cloud.jpg)

上面这张图显式写了 `ag:width`，因此不受任何模板影响 —— **图片参数永远优先于模板规则**。下面的内容只对「没写 `ag:width`、布局为 auto」的图片生效。

## 三条规则的样子

本库预置了 `wide` 模板，它把宽度整体调大一档：

| 比例区间 | 宽度 | 布局 |
| --- | --- | --- |
| `[0.75, 1.35]` | 0.68（栏宽的 68%） | auto |
| `(1.35, 5]` | `0.55 + 0.1 * Math.log(r)` | auto |
| `[0.2, 0.75)` | `Math.max(0.32, 0.3 + 0.2 * r)` | float，靠左 |

第一条覆盖方图，第二条用表达式让宽图的占比随比例缓慢增长，第三条把竖图压窄并允许文字绕排。

区间是左闭右开还是左开右闭，由括号本身决定：`[0.75, 1.35]` 包含 0.75 与 1.35，`(1.35, 5]` 不包含 1.35 但包含 5。

## 规则怎么匹配

从上到下，第一条命中的规则生效，后面的不再看。所以宽泛的区间要放在后面，精确的区间放前面。

每条规则有四个字段：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `ratioRange` | `[0.5,1]`、`(1,3]` | 图片宽高比区间（宽 ÷ 高） |
| `width` | 常数或含 `r` 的表达式 | 占内容宽度的比例 |
| `layout` | `auto` / `float` / `fixed` | auto 按浮动阈值判断；float 强制浮动；fixed 固定居中块 |
| `side` | `auto` / `left` / `right` | 浮动方向；省略时用模板级 `floatAlignment` |

`width` 的表达式只放行 `r` 与 `Math.log / abs / min / max / pow / floor / ceil / round`。写成裸的 `min(...)` 会被判为非法 —— 必须写 `Math.min`。

规则算出的宽度超过「浮动最大生效宽度」时，会改按块布局显示，不再浮动。

## 两个限制

- 设置页只能改模板名称与浮动方向，**不能新建模板，也不能在这里编辑规则** —— 规则只能通过导入写入。
- 规则只对「没有写 `ag:width` 且布局为 auto」的图片生效。
