# T-008 分页对照素材

## B-001 采集工具链

- `pdf-fixtures.mjs`：按 off / images / heading / orphan 四种状态导出 PDF，支持 `--lang` 输出目录。
- `pdf-row-spacer-scan.mjs`：可调空白块，把画廊行放到页边，验证整行预压缩。
- `pdf-orphan-scan.mjs`：按字符数寻找“末页 2–3 行”的段落，对比孤行控制。
- `pdf-float-scan.mjs`：对比 `ordered` / `share` 两种浮动空间模式，以图片页与旁文页判断是否绑定。
- `pdf-single-scan.mjs`：单图专用，可调空白块验证单图压缩。
- `pdf-stills.mjs`：渲染 PDF 页面、裁上下区域、加 6px 主题感知分隔线、输出 1500 宽 WebP。
- 全部脚本走 `background: true` 与 CDP 点击，不抢焦点、不改窗口尺寸。
