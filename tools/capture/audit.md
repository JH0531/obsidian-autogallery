## 编号与版本

AG-<S|A|V><页序号>-<序号>[a|b]；页序号 = 笔记 order + 1，例外：order 20 → 22、order 21 → 23（21 曾被废弃方案占用）。编号不带语言与主题后缀

- from 为空表示从文档顶部开始；to 为空表示到本节最后一个块。界面类素材无锚点，靠 desc 说明取景
- 每条素材都有 lang × theme 四格，落在 media/<lang>/<theme>/ 下；四格各自完成到哪一步只看 media/manifest.json，本文件不记 status
- 主题只改配色不改布局，同一套坐标与动作参数重录；深色 = obsidian，浅色 = moonstone
- kind 表示拍摄通道：缺省 = 内容镜头（shoot-batch）；ui = 界面镜头（winapp/scenes）；pdf = 由 PDF 导出渲染，不在窗口里截
- 内容镜头的 note 是中文笔记路径。英文版内容静帧需要 noteEn（对应英文笔记），未填则该镜头在 en 下拒绝拍摄，避免把中文画面挂到英文目录；kind 为 pdf 时 note/noteEn 是溯源标签，实际拍摄源是 fixtures/pdf-pagination-*.md；kind 为 pdf 时 note/noteEn 是溯源标签，实际拍摄源是 fixtures/pdf-pagination-*.md

状态列的四格按 **en/any → en/dark → en/light → zh/any → zh/dark → zh/light** 排列：`●` 已产出，`○` 待产出。
