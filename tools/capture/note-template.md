# 标题：读者问题的一句话答案

> 一句话结论。读者即使只看这一行，也应该知道这个功能解决什么问题。

（演示区：图片、画廊、表格本身就是样本。不要在这里写「下面我们将展示……」）

## 原理

2–4 行解释为什么会得到这个结果。必要时给一行最关键的源码或公式。

## 写法

```markdown
![说明|ag:参数=值](assets/photo/01-fjord.jpg)
```

一句适用范围 + 一句限制（例如「只对单图生效」「画廊内会被忽略」）。
